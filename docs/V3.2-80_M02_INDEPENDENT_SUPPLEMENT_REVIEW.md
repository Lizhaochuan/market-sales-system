## 本期 CI-only 实现
`src/cross-module-supplement-independent-review.mjs` 通过 V3.2-79 的补充证据 `report` 与 `audit`、V3.2-78 原材料 `audit`，以当前机构/异常/材料类别、来源修订、补充版本、不可变链 SHA-256 摘要和原提交摘要为锚点，追加独立复核记录。

- 复核必须由带外虚构员工映射提供的本机构有效检查者完成，角色匹配 V3.2-78 责任矩阵，且不得与原材料提交人相同。
- 只能核查最新链尾版本；旧补充材料不能复核，出现新一版后旧复核立即不属于当前版本，但历史审计永久保留在 CI 内存样例中。
- 来源版本变化、链摘要不一致、原审核提交记录缺失、检查者被撤权或跨机构引用，一律拒绝；幂等键只能重试当前未被替代的同一复核正文，不允许同版重复审核或换正文。
- 复核成功只返回 `fixture_independent_supplement_review_current=true` 与 `BLOCKED_EXTERNAL_SUPPLEMENT_AUTHORITY_NOT_CONNECTED`；这是虚构材料核对，并非真实财务或教务签名。
