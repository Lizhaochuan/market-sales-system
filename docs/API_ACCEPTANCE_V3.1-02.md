# V3.1-02 API 合同验收矩阵与阻断清单

**文档编号**：MS-API-TEST-001；**版本**：V3.1-02；**状态**：设计用例，全部未执行  
**覆盖**：新系统 `/api/v1`、拟议 CRM `/integration/v1`、独立财务权威适配层。  
**禁止误判**：OpenAPI 文件可解析 ≠ CRM API 已存在 ≠ 联合对接通过 ≠ 真实收款已核验。

## 1. 合同检查（C）

| 编号 | 测试场景 | 必须达成 |
|---|---|---|
| API-C01 | /api/v1 和 /integration/v1 的服务身份不混用 | 只允许各自声明的服务身份与业务范围 |
| API-C02 | 未授权学生查找与家长电话号码查询 | 无权访问或仅返回最少遮蔽字段，不可枚举所有学生 |
| API-C03 | 学生同电话，不同家庭或共享家长 | 只作为待核实候选，不自动合并学生或家庭 |
| API-C04 | 单个学生新建客户 | 不会自动创建 family_groups |
| API-C05 | 一条咨询涉及两名学生 | 接触事件只记一次，两个学生可以关联 |
| API-C06 | 创建学生商机 | 必须是具体学生，负责人继承/改派有权限校验 |
| API-C07 | 课程标准价、计费单位和版本 | CRM 是唯一价格权威，报价保留源版本 |
| API-C08 | CRM 价格变化 | 旧报价不被覆盖；价格过期时正确拒绝或待批准 |
| API-C09 | 试听可用性查询之后资源被他人占用 | CRM 最终确认原子拒绝冲突，不能因查询时可用误报成功 |
| API-C10 | 试听身份不存在且只需要临时试听 | CRM 必须区分临时试听身份和正式报名权益；不能无证据自动建立收费权益 |
| API-C11 | 试听改期与取消 | 使用原预约版本和新的合法业务操作键，原预约历史留痕 |
| API-C12 | 试听真实参与反馈 | 多学生分别记录，不因共享课次丢失个别结果 |

## 2. 失败、幂等与财务测试（F）

| 编号 | 测试场景 | 必须达成 |
|---|---|---|
| API-F01 | 原键原负载重复创建学员 | 只生成一个 CRM 对象；等价原回执 |
| API-F02 | 原键不同负载重复发课 | 409 IDEMPOTENCY_CONFLICT，不创建第二权益 |
| API-F03 | CRM 已提交但响应在网络中丢失 | 前端显示“待核实”；查询原 requestKey，不换新键 |
| API-F04 | CRM 查询原请求结果仍不明 | 保持 manual_review，不推断失败和不自动双写 |
| API-F05 | 合并付款向哥哥 ¥6,000、妹妹 ¥4,000 的两笔订单分配 ¥6,000 | 不超额分配，不能同时认定两笔订单全额成交 |
| API-F06 | 销售手动将订单 payment_state 改成 fully_paid | 不允许生成正式成交或权益 |
| API-F07 | 财务收款未权威确认、仅上传截图或手工声明 | 不产生 SaleEvent |
| API-F08 | 重复接收同一真实付款、退款或财务回调 | 以权威外部交易 ID 去重；乱序状态不覆盖新状态 |
| API-F09 | 两次并发认定同一订单成交 | 只能产生一个首次成交事件 |
| API-F10 | 一条订单明细不同请求键重复申请发课 | CRM 领域唯一键禁止二次发课 |
| API-F11 | 退款金额分配与业绩冲回 | 原始成交不可被删除；退款和业绩调整各自守恒 |
| API-F12 | 销售 A 负责哥哥、B 负责妹妹 | 家庭关系不能拓宽 A 对妹妹订单/报价的访问 |
| API-F13 | 报表与审计 | 首次来源与商机来源不混加；审计显示中文业务前后值 |
| API-F14 | 不存在课程版本/试听安全接口 | 接口返回缺口，不得悄悄走 CRM 管理员通用全表路径 |

## 3. 必须补充的实测证据

- 有效 CRM 集成服务身份、scope 和撤销测试，不共享超级管理员凭据。
- CRM 侧实际实现的接口路径与 deployed SHA、响应示例、授权名单、时间戳和校区/租户归属。
- 开发隔离环境真实 PostgreSQL 迁移与 DB-I01~12 并发事务验证。
- CRM 学员唯一匹配、候选人工确认、临时试听身份及课程售卖规则。
- 真实财务权威系统或正式核对程序的编号、凭证及付款分配审批证据。
- CRM 预约资源冲突验证、结果未知恢复、服务重启后幂等记录仍有效。
- 合同测试的失败、成功和缺口均记录；不能把静态 JSON 校验当作功能 PASS。
- 最终 GUI / 微信开发者工具/浏览器/真机验收由具备设备权限的同事现场执行；不得用模拟器代替真机。
- 正式交付前，所有用户可见的审批和审计差异必须按实际业务内容翻译为自然中文，不显示代码。
