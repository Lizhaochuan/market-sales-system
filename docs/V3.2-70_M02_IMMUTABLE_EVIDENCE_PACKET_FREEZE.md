## 本阶段实现与未实现的明确界线

`src/cross-module-evidence-freeze.mjs` 是**独立隔离测试中的内存模型**，不是可在 CRM、财务和教务运行的正式冻结存储，也不是签名验证服务。它验证将来需要的安全性质：

1. 包含机构 ID、异常 ID、权威来源修订号及每条证据的来源系统、来源事件 ID、事件版本、已提供的 SHA-256 摘要。字段白名单、事件 ID 不重复、条目不超过 100，规范化排序后形成确定性 SHA-256 包摘要。这个摘要只证明本地数据位一致，不证明原始证据真实、完整或已经独立签署。
2. `getTrustedSourceRevision` 由测试环境单独注入，模拟来源系统当前版本；**不得从请求体读取“当前版本”作为可信依据**。同一来源修订只能冻结一次；相同请求键、相同内容可以幂等重试，键重复但正文变化或不同异常复用该键会拒绝。来源版本落后、证据变化但未升版本或事件重复均拒绝。
3. 来源权威版本增加时可创建新的不可变冻结版本，旧版保留为历史但不可再视为当前交接依据。读验证重新比对当前来源版本、冻结版本、哈希、机构和异常归属，拦截过期、改动、错机构及旧包重放。因为没有真实外部签名和正式交接授权，**即使摘要与版本相符，返回 `handoff_allowed=false`、`compensation_write_allowed=false`、`release_eligible=false`、`hold_active=true`**。
4. 模拟注册是进程内 Map，**不具备跨机器共享、持久化、崩溃恢复、真实并发事务或正式数据库约束**。真实落地必须使用由授权权限控制的不可变持久记录、唯一请求键/快照版本约束、数据库事务级 CAS、审计与多节点重试、源系统签名摘要，不能将这个模块直接作为生产 API。
