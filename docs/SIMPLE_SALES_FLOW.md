# 销售操作简化

原则：把时间留给客户；选择优先、默认带入、名称自动生成、说明选填。沿用已有导航名称，不再让销售为同一个客户跨页面重复选学生和商机。

本次已实现：
- 咨询与线索：当前来源下拉可由本线索负责人或主管修改，选择后自动保存；原始咨询记录不覆盖。更新追加到现有审计记录，仍按机构与线索负责人过滤。
- 销售商机：每条商机直接提供“记跟进、约试听、做报价”，带入学生及商机，沿用次日默认时间和试听时段选择。
- 业务计划与任务：说明可留空并自动命名；课程可选择常见科目或自行输入；数量明确为课时数，按每课时价格计算合计；同时显示此前预计金额作为参考，不自动改写预计金额。
- 报价记录：直接点击“生成报名意向”，带入该报价的当前版本。

原有金额和历史数据不重算；当前课时数沿用既有正整数约束。自选科目仅为输入建议，不是CRM标准课程目录或正式定价。真实排课、到账、成交仍需要外部确认。

没有修改001—038迁移、没有解除HOLD或开放严格员工模式。现有草稿与独立审批数据保留。尚未整合的市场人员账号及真实成交流程不能声称已完成。
