## 本阶段实现
新增 `src/cross-module-unified-pending-review-report.mjs`，只在虚构 CI 中组合 V3.2-82 统一门禁、V3.2-86 证据差异与 V3.2-87 任务报告，分别从三个独立测试适配器取结果，不接收请求正文自行宣称“已批准”或“复核完成”的状态。

- 精确检查机构及异常、新旧审计序号与摘要，核对六类外部真实验收缺口完整且各自保持 `requires_external_authority`。
- 复核任务必须与差异项逐条一致：任务总数、唯一项目、责任部门、状态、SHA-256 差异摘要及未完成数量不能不一致。任何遗漏、虚假完成、被撤销复核人或缺失报告均 fail closed。
- 先运行既有统一门禁，核对其仍返回 `BLOCKED_REAL_THREE_PARTY_ATOMIC_HANDOFF_MISSING` 和全部业务授权 false，才允许生成只读报告。
- 第一遍读取后模拟异步变化，再完整重读两遍；如果复核状态、差异摘要或六项外部缺口在读取期间变化，则拒绝报告为稳定。三次检查仍不是外部原子锁。
- 输出当前未完成任务列表、责任部门、状态、任务总数、未完成数以及仍开放的六类外部条件。即使内部任务数变为零，也始终 `BLOCKED_EXTERNAL_HANDOFF_AND_TASK_REVIEW_REQUIREMENTS`，绝不自动交接。

## 非生产边界
这是 CI-only 虚构任务聚合器，无持久化任务队列、外部身份、金融/教务真实签名、原账和课时对账、三方权威签收或原子交接。所有返回维持 `finance_authorized=false`、`academic_authorized=false`、`handoff_allowed=false`、`compensation_write_allowed=false`、`release_eligible=false`、`hold_active=true`。学生是管理主单位，家庭按需关联；错绑的原订单、资金、SaleEvent、课时与补偿记录均保留。16 项外部准入及 R01—R10 未通过，合同 `proposed-unimplemented`；迁移仍 001—038，无 039。不合并、不部署、不修改 `edu-management-system`，市场销售技术文档独立维护。
