# V3.2-81｜M02 补充材料与独立复核最终一致性、并发失效强阻断

## 本期 CI-only 实现
新增 `src/cross-module-supplement-review-final-check.mjs` 与独立测试，组合 V3.2-79 的补充版本链 `report`/`audit` 及 V3.2-80 的独立复核 `report`/`audit`，而不是信任客户端传入的“已审核”字段。

1. 校验当前机构、异常、六类证据要求，并要求当前来源版本/补充版本/最新 SHA-256 链摘要匹配；同时核对原始提交摘要、补充人和复核人的历史关系。
2. 第一遍检查之后，执行仅用于 CI 模拟的异步动作；再次读取补充材料和复核状态。新补充版本、撤销复核人、来源修订改变、跨机构引用或依赖异常均拒绝。末尾额外读取一次以检测读取过程中的局部变化。
3. 新版材料出现后，旧版复核仍保留历史，但不得被视为当前有效；复核必须与最新版本及链摘要逐一绑定。
4. 即使三次检查均一致，也只能返回 `fixture_supplement_review_consistent=true` 和 `BLOCKED_NONATOMIC_EXTERNAL_AUTHORITY_NOT_CONNECTED`。测试不是跨系统原子锁，检查结束后仍存在并发窗口，绝不形成正式交接权限。
