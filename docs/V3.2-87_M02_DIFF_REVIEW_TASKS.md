## 本次隔离实现
`src/cross-module-diff-review-tasks.mjs` 从 V3.2-86 的只读差异报告获取具体差异和六项未完成外部验收缺口。仅接受受信 CI 测试框架注入的来源与人员适配器；不能接受客户端伪造的已审批字段。

- 对每条真实存在于虚构差异报告中的差异建立当前比较摘要和每项差异摘要，任务责任部门继承 V3.2-86 的销售、财务、教务分配。
- 流程严格为待复核（pending）→ 复核中（in_review）→ 内部行政完成（closed_administratively）；先开始后完成，完成者必须独立于开始复核的人。
- 来源变更、差异内容或版本发生变化时重新计算比较摘要，旧任务及复核记录作为历史保留但对最新报告自动失效。
- 按当前有效人员权限重新核对完成记录；权限撤销则标记 `reviewer_revoked_recheck_required`，禁止复用旧完成结论。
- 报告包含任务数量、未完成数量、各项归属与状态。即使所有内部任务完成，仍固定返回 `BLOCKED_EXTERNAL_HANDOFF_EVEN_IF_TASKS_COMPLETE`，不得放行交接。
- 严格限制请求字段及机构、异常、审计版本引用；同幂等键换正文、非法状态流转及跨机构审核均拒绝。

## 不可越界的边界
仅 Node CI 进程内存测试，不提供生产级持久审计、外部真实身份验证、交易执行 API、财务/教务签名、三方权威验收或原子交接。所有响应始终 `finance_authorized=false`、`academic_authorized=false`、`handoff_allowed=false`、`compensation_write_allowed=false`、`release_eligible=false`、`hold_active=true`。
