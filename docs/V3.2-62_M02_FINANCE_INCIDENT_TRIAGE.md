## 业务范围

1. 原销售审核申请人或实际独立销售审批人可以登记交接材料异常。只有经数据库确认的快照不一致，才允许选择 integrity_mismatch；人工发现缺少支持材料可以选择 supporting_materials_gap。请求绑定凭据索引、原因及防重复编号。
2. 本机构另一名当前有效销售主管才能复核。支持人工升级 escalate_manual，或针对佐证缺口、且冻结活动快照仍然完全一致的情况，标记 close_for_recheck（仅重新核查，不是财务批准）。
3. open 或 manual_escalated 使财务交接 readiness_status 变成 blocked_active_incident；即便支持材料问题已关闭，最多回到 ready_for_external_manual_check。错误快照不能自行关闭，人工升级后持续阻断。
4. 只读列表显示最少字段，员工仅见自己相关的交接异常；同机构有效主管仅见待复核或自己经手的记录。原始证据、理由、内部请求键不返回。失败时中文页面清空旧异常并禁止操作。
5. 使用只读安全视图与 SECURITY DEFINER 函数，限制 RS256 签名员工、独立数据库读写 LOGIN、单机构角色、防重复及并发冲突；真实 PostgreSQL、HTTP、Chromium 与静态合同纳入完整 CI。
